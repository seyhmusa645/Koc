Makine Kimliði ve Request Code
------------------------------
- Kurulum sýrasýnda `hardwareId = SHA256(cpuId + diskSerial + installGuid)` üret.
  - `cpuId`: `os.cpus()[0].model + os.cpus()[0].speed` (veya Windows WMI komutu)
  - `diskSerial`: Electron ana süreçte `wmic diskdrive get serialnumber` gibi komutla okunabilir.
  - `installGuid`: Ýlk çalýþtýrmada oluþturulup `install.json` içinde saklanan random UUID.
- Request code = Base64Url(hardwareId).
- Auth penceresinde “Lisans iste” butonu request code’u gösterip kopyalama saðlar.

Lisans Anahtarý Formatý
-----------------------
- JWT benzeri yapý: `<base64url(header)>.<base64url(payload)>.<base64url(signature)>`.
- Header: { "alg": "ES256", "typ": "LICENSE" } (örnek; ES256 public-key imzasý önerilir).
- Payload alanlarý:
  - `requestCode`
  - `schoolName`
  - `plan`
  - `issuedAt`
  - `expiresAt`
  - `maxUsers` (opsiyonel kota)
- Signature: ECDSA (ES256) veya RSA (RS256). Uygulamaya yalnýzca PUBLIC KEY gömülür.
- Lisans dosyasý text (.lic) veya JSON olabilir; UI hem ham string hem dosya yüklemeyi desteklesin.

Offline Lisans Üretim Aracý
---------------------------
Yeni script: `scripts/generate_license.js`
- CLI argümanlarý: `--request`, `--school`, `--plan`, `--expires`, `--maxUsers`.
- Gizli anahtar (private key) burada tutulur, uygulama paketine eklenmez.
- Çýktý: `.lic` dosyasý veya STDOUT.
- Girdiler doðrulanmazsa hata mesajý göster.

Kullanýcý Kayýt / Giriþ Akýþlarý

Registration (yalnýzca aktif lisans varken):
