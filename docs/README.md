# 🎓 Kapsul Koçluk Programı

## 📋 Açıklama
Kapsul Koçluk Programı, öğrenci performansını analiz eden, kişiselleştirilmiş öğrenme planları oluşturan ve sınıf analizi yapan kapsamlı bir eğitim yönetim sistemidir.

## ✨ Özellikler

### 🧠 Akıllı Öğrenci Analizi
- **AI Destekli Değerlendirme:** Gemini AI ile kapsamlı öğrenci analizi
- **Zeka Türü Analizi:** 8 farklı zeka türüne göre değerlendirme
- **Öğrenme Stili Tespiti:** AYRIŞTIRAN, ÖZÜMSEYEN, YERLEŞTİREN, DEĞİŞTİREN
- **Performans Takibi:** Detaylı sınav geçmişi ve trend analizi

### 📊 Sınıf Analizi
- **Zeka Türü Dağılımı:** Görsel grafiklerle sınıf profili
- **Öğrenme Stili Analizi:** Sınıf geneli öğrenme stilleri
- **Etkinlik Önerileri:** Zeka türüne göre kişiselleştirilmiş etkinlikler
- **Sınıf Karşılaştırması:** Sınıflar arası performans karşılaştırması

### 📚 Ders Planlayıcı
- **Akıllı Planlama:** Zeka türü ve öğrenme stiline göre planlama
- **Kazanım Takibi:** MEB müfredatına uygun kazanım takibi
- **Etkinlik Önerileri:** Çeşitli öğrenme stillerine uygun etkinlikler

### 📈 Raporlama
- **PDF Export:** Profesyonel raporlar
- **Görsel Analizler:** Grafik ve chart'larla veri görselleştirme
- **Detaylı İstatistikler:** Kapsamlı performans metrikleri

## 🚀 Kurulum

### Gereksinimler
- Node.js (v14 veya üzeri)
- npm veya yarn
- Electron

### Kurulum Adımları
```bash
# Projeyi klonlayın
git clone https://github.com/kullaniciadi/kapsul-kocluk-programi.git

# Bağımlılıkları yükleyin
npm install

# Uygulamayı başlatın
npm start
```

## 📖 Kullanım

1. **Öğrenci Ekleme:** Yeni öğrenci profilleri oluşturun
2. **Sınav Ekleme:** Öğrenci sınav sonuçlarını girin
3. **Analiz:** AI destekli öğrenci değerlendirmesi yapın
4. **Planlama:** Kişiselleştirilmiş ders planları oluşturun
5. **Raporlama:** Detaylı raporlar oluşturun ve PDF olarak kaydedin

## 🔧 Teknik Detaylar

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Electron (Node.js)
- **AI:** Google Gemini API
- **Veri:** JSON tabanlı veri saklama
- **PDF:** Electron PDF export
